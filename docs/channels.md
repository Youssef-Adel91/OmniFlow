# القنوات — ما يعمل فعلًا وما ينقص

**القاعدة:** ✅ = شغّال ومختبر محليًا بـ mocks · 🟡 = مبني لكن **لم يُجرَّب مع Meta/Telegram الحقيقيين** · ⛔ = غير موجود. لا شيء هنا جُرِّب على إنتاج Meta.

| القناة | استقبال | رد نص | وسائط صادرة / أزرار | التعليقات | الحالة |
|---|---|---|---|---|---|
| WhatsApp Cloud API | ✅ نص/وسائط | ✅ | قوالب (حملات + متابعة المبيعات) ✅؛ صور/أزرار ⛔ | — | 🟡 |
| Instagram DM | ✅ نص + مرفقات + postback | ✅ | ⛔ (نص فقط) | ✅ رد علني / رد خاص / إخفاء (PR #33) | 🟡 |
| Facebook Messenger | ✅ نص + مرفقات + postback | ✅ | ⛔ (نص فقط) | ✅ عبر حقل `feed` (PR #33) | 🟡 |
| Telegram | 🟡 المحوّل فقط (تحقق السر + التحليل) | 🟡 `sendMessage` | ⛔ | — | **محوّل + اختبارات؛ غير موصول بمسار ويب ولا بشاشة ربط** |
| TikTok / X / Snapchat | ⛔ | ⛔ | ⛔ | — | خارج v1 (مقصود) |

## ربط كل قناة (للمدير)
- **WhatsApp:** الإعدادات ← القنوات ← الربط عبر Embedded Signup (خلف علم `FEATURE_WHATSAPP_EMBEDDED_SIGNUP`) أو إدخال Phone Number ID والتوكن يدويًا. زر «رسالة تجريبية» يرسل رسالة حقيقية لرقم تحدده (للمدير، 5 مرات/ساعة، مع سجل تدقيق).
- **Instagram + Facebook:** زر «الربط عبر فيسبوك» (OAuth). يشترك التطبيق في حقول الصفحة `messages, messaging_postbacks, message_deliveries, message_reads, message_reactions, feed, mention` (مع الرجوع للمجموعة الأقدم إن رفضتها Meta). **«comments» ليس حقل صفحة** في Meta — التعليقات تصل عبر `feed`.
- **تشخيص:** «ما الناقص؟» في الإعدادات ← القنوات، و`scripts/meta_check_subscriptions.py` يفحص الاشتراكات والصلاحيات دون تغيير شيء.
- **انتهاء التوكن (خطأ 190):** يصل من Meta بـ HTTP 400؛ يُصنَّف الآن صحيحًا، ويظهر شريط «أعد الربط» وتنبيه للأدمن.

## قواعد Meta التي يطبّقها الكود
- **نافذة 24 ساعة (واتساب):** خارجها لا يُسمح إلا بقالب معتمد. الـ dispatcher يفحصها الآن قبل أي إرسال حر: خارج 24 ساعة تُعلَّم الرسالة FAILED بسبب مقروء ولا تُرسل لـ Meta (القوالب مستثناة)، ومتابعة المبيعات تستخدم القالب المعتمد خارجها. **غير مجرَّب على واتساب حقيقي.**
- **Private Reply:** مرة واحدة لكل تعليق وخلال 7 أيام.
- **التعليقات:** لا ردّ على تعليقات الصفحة نفسها ولا على الردود المتداخلة؛ لا تكرار؛ سقف في الدقيقة وفي الساعة؛ ساعات عمل؛ ردود علنية بقالب ثابت بلا أسعار أو وعود.

## الفجوات المعروفة (بالأولوية)
1. صور/أزرار سريعة صادرة على IG وMessenger (يحتاج روابط صور للعقارات، وهي غير مخزنة اليوم).
2. Telegram: `src/channel_adapters/telegram/adapter.py` جاهز (تحقق `X-Telegram-Bot-Api-Secret-Token` بمقارنة ثابتة الزمن وإغلاق عند غياب السر، محادثات خاصة فقط، نص/صوت/صورة/ملف، إرسال نص مع تصنيف الأخطاء). **ينقص:** مسار `POST /webhooks/telegram/{...}` وتخزين توكن البوت مشفّرًا لكل مستأجر (جدول + migration + RLS)، شاشة الربط، فرع في الـ dispatcher، و`setWebhook`. لم يُجرَّب مع Telegram حقيقي.
3. لم يُجرَّب أي شيء على حسابات Meta حقيقية؛ مراجعة التطبيق (App Review) لم تُقدَّم.

## واجهة `ChannelAdapter` (`src/channel_adapters/base.py`)
عقد موحّد للقنوات الجديدة: `verify(headers, raw_body)` (تحقق قبل أي تحليل، مقارنة ثابتة الزمن) · `parse(payload, tenant_id)` ← قائمة `CanonicalInboundEvent` (لا يرمي استثناءً على حمولة لا يفهمها) · `send_text(token, to, text)` ← معرّف الرسالة، ويرمي `ChannelSendError(auth=True)` عند توكن ميت (ليغذّي تنبيه إعادة الربط). Telegram أول من يطبّقه؛ واتساب وإنستجرام وماسنجر ما زالت تنفّذ الواجبات نفسها داخل routers خاصة بها ولم تُنقل إلى الواجهة (لم يُعاد هيكلتها حتى لا نخاطر بقنوات تعمل).
